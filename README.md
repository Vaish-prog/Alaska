# Alaska - AI Voice Assistant

Alaska is a Python-based AI voice assistant that listens to voice commands, performs useful computer tasks, and answers general questions using AI.

## Features

- Wake-word detection using "Alaska"
- Speech recognition
- Text-to-speech responses
- AI-powered question answering
- Open Google
- Open YouTube
- Open Instagram
- Search Google
- Search YouTube
- Search Wikipedia
- Open Notepad
- Open Calculator
- Open Visual Studio Code
- Tell the current time
- Tell the current date
- Respond to basic personal commands
- Stop/exit command

## Technologies Used

- Python
- SpeechRecognition
- PyAudio
- pyttsx3
- Requests
- OpenRouter API
- Google Speech Recognition
- Webbrowser
- Python OS module
